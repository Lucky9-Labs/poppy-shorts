# Footage drop folder

Put **public, cleared** vertical clips and stills here, then reference them from a beat:

```ts
source: {type: "video", src: "footage/boss-hit.mp4"}
source: {type: "image", src: "footage/hangar.png"}
```

Rules for poppy-shorts (public Lucky9 Labs repo):

- No private mech-game assets, unreleased builds, or secrets.
- Prefer 9:16 (1080×1920) or shots you are happy to center-crop.
- Keep binaries out of git unless they are small, licensed, and meant for the example.
